6. KNOWN GOTCHAS & ARCHITECTURAL SUBTLETIES
--------------------------------------------------------------------------------
1. MENTOR IMAGE PATH MISMATCH:
   - In `public/images/mentors/`, files are named with hyphens:
     `mentor-01.jpg` .. `mentor-32.jpg` (EXCEPT mentor 13 which is `mentor-13.webp`).
   - If `src/data/mentors.ts` points to `/images/people/mentors/mentor_${num}.jpg`,
     those images fail because `public/images/people/mentors/` is currently empty.
   - Always ensure `mentors.ts` maps to the actual existing filenames.

2. IMAGE FILE SIZE & RETINA OPTIMIZATION:
   - `public/images/branding/mandal-logo.png` is 2.62 MB. For faster initial LCP,
     consider using a compressed WebP derivative (<150KB).
   - In `src/data/team.ts`, PNGs in `/images/people/leadership/` are ~1.9 MB each (~24MB total).
     The script `scripts/generate_optimized_portraits.py` created 800x800 WebP portraits
     under `public/images/members/optimized/` (~80 KB each). Switching to these saves ~95%
     of page weight while maintaining crisp clarity.

3. WORDPRESS EMBEDDED VIDEOS:
   - Videos for 2023 & 2024 Vadyapujan are embedded from `video.wordpress.com`.
   - If the free WordPress site is ever deleted, these embeds will fail.
   - Ideal long-term fix: Re-upload to the mandal's YouTube channel (@bhgvvadal)
     and update `src/data/media.ts` to standard YouTube embeds.

4. NEXT IMAGE DOMAINS:
   - `next.config.mjs` allows `dhrmveersambhajikridamandal.wordpress.com` under
     `remotePatterns` for fallback remote loading if ever needed.
