# धर्मवीर संभाजी क्रीडा मंडळ (भगवं वादळ) — अधिकृत संकेतस्थळ

> **छत्रपती संभाजीनगरमधील मानाचा गणेशोत्सव आणि प्रख्यात ढोल ताशा पथक (स्थापना: १९९१)**

हे संकेतस्थळ **Next.js 14 (App Router)**, **TypeScript**, आणि **Tailwind CSS** चा वापर करून बनवले गेले आहे. हे पूर्णपणे स्टॅटिक (SSG) असून व्हर्सेल (Vercel) वर थेट डिप्लॉय होण्यासाठी तयार आहे.

---

## 🌟 प्रमुख वैशिष्ट्ये

1. ** अस्सल मराठी मजकूर व मांडणी (Authentic Marathi Copy & Typography):**
   - Google Fonts कडून `Yatra One` (शीर्षके) आणि `Baloo 2` (मजकूर).
   - शुद्ध व सुस्पष्ट देवनागरी मांडणी (`<html lang="mr">`).

2. **🎨 सांस्कृतिक व भगवा रंगसंगती (Festive Bhagwa Palette):**
   - भगवा (Saffron `#FF6F00`), कुंकुम/मरून (`#800B22`), सोनेरी व उबदार क्रीमी पार्श्वभूमी.
   - मंडळाच्या नावाप्रमाणे (भगवं वादळ) तेजस्वी आणि मंगलमय वातावरण.

3. **📸 २०९ अस्सल छायाचित्रांचे स्थानिक संकलन (Self-Hosted Photos):**
   - सर्व छायाचित्रे थेट वर्डप्रेस अपलोड स्त्रोतातून डाउनलोड करून `/public/images/` मध्ये स्वयंचलित साठवली आहेत.
   - वर्डप्रेस हॉटलिंकिंगवर कोणतेही अवलंबित्व नाही.
   - `next/image` द्वारे स्वयंचलित ऑप्टिमायझेशन व लेझी लोडिंग.

4. **👥 मंडळ परिवार व मार्गदर्शक (Roster & Guides):**
   - १२ अधिकृत पदाधिकारी कार्ड्स (कै. लक्ष्मण अण्णा थोरात यांच्यासाठी विशेष आदरणीय स्मृती डिझाइन).
   - ३ विशेष सहकार्य छायाचित्रे.
   - ३२ मार्गदर्शक छायाचित्रांची आकर्षक ग्रिड (कोणतेही काल्पनिक नाव न देता).

5. **🎥 ऐतिहासिक क्षण व व्हिडिओ (Media & Historical Moments):**
   - **१९९१ चा भगवं वादळ पहिला फोटो:** मंडळाची ऐतिहासिक स्थापना दाखवणारे विशेष प्रमुख कार्ड.
   - **वाद्यपूजन २०२२:** ऐतिहासिक छायाचित्र.
   - **वाद्यपूजन २०२३ व २०२४:** रिस्पॉन्सिव्ह १६:९ व्हिडिओ एम्बेड्स.
   - **३ YouTube व्हिडिओ:** पथकाच्या वादनाचे थेट व्हिडिओ.
   - **Instagram Reels:** अधिकृत पेजला जोडणारे कार्ड (`@bhgv__vadal`).

6. **🖼️ संपूर्ण छायाचित्र गॅलरी (`/gallery`):**
   - **2K23 PHOTO'S:** २०२३ गणेशोत्सवाची ७९ छायाचित्रे.
   - **Old Photo's:** जुनी संग्रहित ८० छायाचित्रे.
   - मोबाईल कार्यक्षमता वाढवण्यासाठी २४-२४ च्या तुकड्यांमध्ये "Load More" पॅजिनेशन.
   - कीबोर्ड, स्वाइप व डाउनलोड पर्यायांसह फुलस्क्रीन लाइटबॉक्स (Lightbox Modal).

7. **📱 मोबाईल-फर्स्ट डिझाइन (Mobile-First):**
   - ३७५px मोबाईल स्क्रीनपासून मोठ्या डेस्कटॉपपर्यंत सुलभ नेव्हिगेशन.
   - किमान ४४px टॅप टार्गेट्स, हॅम्बर्गर मेनू, जलद लोड होणारे पेज (First Load JS फक्त ~८७ kB).

## 🛠️ प्रोजेक्ट चालवणे (Getting Started)

### १. डेव्हलपमेंट सर्व्हर सुरू करा
```bash
npm run dev
```
ब्राउझरमध्ये [http://localhost:3000](http://localhost:3000) उघडा.

### २. नवीन छायाचित्रे पुन्हा डाउनलोड करणे (पर्यायी)
```bash
npm run download:images
```

### ३. प्रॉडक्शन बिल्ड (Production Build)
```bash
npm run build
```

## 🚀 Vercel वर डिप्लॉय करणे

हे संकेतस्थळ कोणत्याही API किंवा डेटाबेसवर अवलंबून नाही. कोणत्याही पर्यावरण व्हेरिएबल्स (Environment Variables) शिवाय हे Vercel वर एका क्लिकमध्ये डिप्लॉय होते:

1. कोड GitHub रिपॉझिटरीमध्ये पुश करा.
2. Vercel वर "New Project" निवडून ही रिपॉझिटरी इम्पोर्ट करा.
3. "Deploy" वर क्लिक करा.
